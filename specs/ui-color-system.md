# 紫色品牌与交互配色

保留深色工作台和现有布局。品牌操作统一紫色，成功绿色，警告黄色，失败及危险操作红色；状态必须同时显示文字或图标。

- 品牌主色 #9333EA，悬停 #7E22CE，白色按钮文字；明暗主题一致。
- 主要、次要、轻量、危险按钮共用公共组件；每个独立操作区域突出一个主要动作。
- 上传、导入、查看版本及列表编辑为次要操作；刷新、取消、返回为轻量操作。
- 导航、页签、表单焦点和选中态复用品牌变量；中性背景保持现状。
- 成功、素材可用保持绿色；媒体内容、业务分类和图表系列不机械替换。
- 主题颜色集中在 styles/theme.css；页面不新增重复的品牌颜色字面量。
- 不修改 API、数据库、任务及媒体链路；不新增主题切换。

验收：类型检查、lint、测试、构建通过；检查主要页面、弹窗、加载和禁用状态；按钮文字对比度至少 4.5:1，键盘焦点可见，操作不回归。发布另行授权。
