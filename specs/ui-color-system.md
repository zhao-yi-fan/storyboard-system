# 紫色品牌与交互配色

保留深色工作台和现有布局。品牌操作统一紫色，成功绿色，警告黄色，失败及危险操作红色；状态必须同时显示文字或图标。

- 品牌主色 #9333EA，悬停 #7E22CE，白色按钮文字；明暗主题一致。
- 主要、次要、轻量、危险按钮共用公共组件；每个独立操作区域突出一个主要动作。
- 上传、导入、查看版本及列表编辑为次要操作；刷新、取消、返回为轻量操作。
- 导航、页签、表单焦点和选中态复用品牌变量；中性背景保持现状。
- 成功、素材可用保持绿色；媒体内容、业务分类和图表系列不机械替换。
- 主题颜色集中在 styles/theme.css；页面不新增重复的品牌颜色字面量。
- 不修改 API、数据库、任务及媒体链路；不新增主题切换。

## 页签与点击反馈

- 公共页签提供 pill（默认）与 underline 变体；资产分类使用紫色文字和2px底线，不出现四边紫框。底线空间始终预留，焦点独立可见。
- 所有有效按钮、图标、菜单、分类切换及按钮式卡片有 hover/active/focus-visible 反馈；主要紫色、次要中性、危险红色、链接下划线。选中状态不能被 hover 覆盖。
- hover 仅 hover:hover 且 pointer:fine 启用；禁用/aria-disabled/data-disabled 不可激活且无可点击悬停反馈。触屏仍有 active，减少动态效果时无过渡。
- 过渡150ms，仅颜色/背景/边框/阴影，不使用位移或缩放；媒体预览只强调边缘，不染色图片视频。

## 文本输入焦点

- Input、Textarea 共同管理焦点：保持 1px 边框，聚焦使用品牌色边框和 2px、25% 透明度、无偏移光圈，不叠加 outline；鼠标和键盘一致，不改变尺寸。
- 全局 outline 仅为未封装的原生输入控件兜底，按钮等其他控件规则不变。页面负责布局和背景，不另加焦点光圈。
- aria-invalid 优先使用危险色边框及光圈；禁用或 aria-disabled 无聚焦光圈，减少动态效果时关闭过渡。

# 媒体卡片描边层

媒体 hover / active 描边使用位于子图片上方的 1px 独立伪元素层，禁止仅使用父元素内侧阴影。描边继承卡片圆角，不占布局空间、不拦截点击；键盘焦点外圈独立保留 2px。

版本卡片由最外层绘制描边，覆盖图片与底部版本标签；详情和全部版本弹窗复用 VersionImageCard。悬停/按下仅由预览按钮触发，不把切换按钮的禁用状态当成整个卡片禁用。预览键盘焦点以外层 2px 内描边显示，避免被卡片 overflow 裁切；当前版本选中外圈独立保留。项目封面与本集准备只高亮图片区域，上角匹配外层卡片内圆角，下角保持直角，不扩展到文字区。
