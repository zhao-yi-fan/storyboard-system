# 浏览器直连私有 OSS

## 目标与数据流

生产入口为 `https://popreels.zhaoyifan.top`。已授权业务 API 将数据库的稳定
`/generated/**` 引用（包括旧 OSS 地址）转换成公网 HTTPS GET 签名。
浏览器直接访问私有 OSS；Node 仅签名，不传输媒体文件。不接入 CDN，不迁移数据库。

## URL 与续期

- 浏览器签名按 20 分钟固定窗口，到期时间为窗口起点 + 60 分钟，剩余有效期 40–60 分钟；跨 worker / 进程重启结果一致，无共享状态。
- 浏览器 GET 签名统一覆盖 OSS 响应 `Cache-Control: private, max-age=300`，保留 OSS 校验头。SDK 签名到期时间必须等于目标，跨秒最多尝试三次，否则抛出不含 URL 的错误。
- 服务端下载和 AI 调用仍使用独立一小时签名，无浏览器缓存覆盖；上传签名不变。业务 API 鉴权及 no-store 不变。
- 不添加前端持久化缓存、Redis 或数据表；同窗口复用不承诺跨窗口不下载。新图片和预览生成使用新对象身份，历史对象不迁移。
- 浏览器可能在签名失效后继续展示已缓存内容，退出或撤权不等于清除本机缓存。

- 所有图片、视频、音频、海报、缩略图、媒体版本、工作台及 AI 引用预览均走统一解析。
- 上传响应的持久化路径保持不变；后端任务使用独立服务端签名/下载逻辑。
- 共享客户端记录签名与对应 GET 业务请求；已挂载媒体在前台每 30 秒检查一次，
  到期前五分钟刷新业务接口。同一接口并发刷新合并。后台暂停检查，恢复前台立即检查。
- 预览打开检查有效期。正常播放保持当前 src；加载失败只自动刷新一次，失败显示重试。
  恢复视频时保留时间点与播放状态。签名不得作为 React 元素的身份。
- 抽帧下载使用最新签名，403 刷新后最多重试一次；已有 Blob 无需续期，关闭后释放。
- 根鉴权路由提供 HydrateFallback，首屏懒加载时显示加载状态。

## 配置与权限

生产 Nginx `/generated/` 和 `/_media/stream/` 显式 404，Node 删除流接口。
无 OSS 的本地开发继续使用 Node/Vite 静态目录。OSS CORS 允许生产域名及 localhost:5173
的 GET/HEAD 与 Range；暴露 Content-Length、Content-Range、Accept-Ranges、ETag。
更新规则保留其他来源规则。Bucket 仍为私有；签名为临时 bearer 授权，不写入日志。

## 固定窗口缓存本地验收（2026-10-20）

- 使用真实 SDK 和假凭证离线测试同窗口签名一致性、跨 worker 配置实例、旧 OSS 引用、20 分钟边界、SDK 跨秒竞态及三次失败上限；没有调用生产 OSS。
- 前端测试覆盖相同签名无通知且图片 DOM/src 不变、续期合并、前后台恢复、失败一次恢复及播放中的视频不换源。
- 写入路径核查：原图生成入口按实体与时间戳创建新文件，上传使用时间戳和随机标识，抽帧包含视频版本与时间信息；固定名称的预览/海报重新生成存在覆盖风险，已在公共预览写入层追加 UUID，数据库继续使用函数返回的新路径，已有对象不迁移。
- 服务端下载与 AI 客户端仍走 resolveSignedUrl / OSS get；浏览器业务映射走 resolveUrl；GET 浏览器缓存参数不影响 PUT 上传。
- 当前数据库隧道不可达，数据库真实集成未验收；单元测试通过不代表真实数据库连接成功。
- 当前没有可用浏览器控制工具，首次加载/普通刷新/页面往返的真实缓存响应头和传输量、线上匿名对象拒绝访问及实际换图未验收。不得据此宣称实际缓存命中。
- 未提交、推送、部署；未新增前端持久化缓存、共享缓存服务、数据表或生产 Bucket 元数据修改。
