# 浏览器直连私有 OSS

## 目标与数据流

生产入口为 `https://popreels.zhaoyifan.top`。已授权业务 API 将数据库的稳定
`/generated/**` 引用（包括旧 OSS 地址）转换成新的公网 HTTPS GET 签名，有效期一小时。
浏览器直接访问私有 OSS；Node 仅签名，不传输媒体文件。不接入 CDN，不迁移数据库。

## URL 与续期

- 所有图片、视频、音频、海报、缩略图、媒体版本、工作台及 AI 引用预览均走统一解析。
- 上传响应的持久化路径保持不变；后端任务使用独立服务端签名/下载逻辑。
- 共享客户端记录签名与对应 GET 业务请求；已挂载媒体在前台每 30 秒检查一次，
  到期前五分钟刷新业务接口。同一接口并发刷新合并。后台暂停检查，恢复前台立即检查。
- 预览打开检查有效期。正常播放保持当前 src；加载失败只自动刷新一次，失败显示重试。
  恢复视频时保留时间点与播放状态。签名不得作为 React 元素的身份。
- 抽帧下载使用最新签名，403 刷新后最多重试一次；已有 Blob 无需续期，关闭后释放。
- 根鉴权路由提供 HydrateFallback，首屏懒加载时显示加载状态。

## 配置与权限

生产 Nginx `/generated/` 和 `/_media/stream/` 显式 404，Node 删除流接口。
无 OSS 的本地开发继续使用 Node/Vite 静态目录。OSS CORS 允许生产域名及 localhost:5173
的 GET/HEAD 与 Range；暴露 Content-Length、Content-Range、Accept-Ranges、ETag。
更新规则保留其他来源规则。Bucket 仍为私有；签名为临时 bearer 授权，不写入日志。

## 验收与发布

类型检查、lint、相关测试与前端构建通过；稳定键/旧签名得到新签名。
浏览器图片加载、视频播放/拖动、抽帧保存和下载无跨域错误；短签名测试续期与恢复。
有效数据库媒体均可访问，软删除记录排除；匿名 OSS 对象仍拒绝。
发布通过 main 的 GitHub Actions；配置 CORS 在安装关闭代理的 Nginx 模板前完成。
