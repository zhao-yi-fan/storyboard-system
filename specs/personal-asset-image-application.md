# 个人资产新增与选图

顶部导入新增项目快照，不绑定集。详情“从个人空间选择图片”位于主设定图/封面区域，面向实体而非需求；选择后预览，确认才持久化。角色仅改主设定图，场景/道具仅改封面和缩略图；名称、描述、参考图、原文件及语音保持不变。

新增 POST /personal-assets/:id/apply-image，body 为 project_id/entity_type/entity_id；旧 import-to-project 的 requirement_id 转为安全选图兼容。所有写入同一事务；校验所有权、软删除、分类、图片地址，锁定实体，拒绝图片生成中更换。保存旧图版本、个人来源的新版本及实体/需求当前状态。重复采用当前图返回无变化。新版本来源 personal-import，不假标 AI。

asset_versions 增加可空 source_personal_asset_id，通过独立 ensure 步骤和 schema_migrations 管理。历史版本切换复用锁和实体/需求更新。新增快照与个人素材不持续同步、不复制删除 OSS 文件。

弹窗 create/apply-image 两种模式；先走草稿保护，失败不离开。提交成功刷新失败只允许重刷，不再次提交。忙时阻止重复提交、选择和关闭。保存到个人空间文案不使用“同步”。不扩展参考图能力；保持布局和生成配置。

验收覆盖权限、分类、事务回滚、生成中拒绝、版本补录/恢复、无变化、旧接口兼容及新增不绑定；前端覆盖预览确认/取消、请求失败/刷新失败、草稿保护。执行前后端类型/lint/测试与前端构建；真实数据库和浏览器验收单独记录。只做本地修改，不提交部署。
