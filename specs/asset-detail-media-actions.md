# 资产详情素材操作区

场景、道具详情的原始素材和 AI 封面各自包含标题、图片及紧邻操作。无图不渲染图片占位框：原始素材显示上传；封面显示生成及个人空间选择。有图使用替换/重新生成文案，按钮距图片 8px。无图生成是主要操作，其余为次要操作。按侧栏实际可用宽度自适应为一列或两列。

继续复用现有上传、生成预览确认、草稿保护和个人选图流程，个人选图只改封面。生成时保留旧图并禁止重复生成；上传中禁止重复上传；错误在对应素材区持久显示。图片请求失败继续视为已有素材，复用签名续期和手动加载重试，不调用付费生成。无 API 或数据库变更。

验收覆盖无图、有图、加载失败、上传中、生成中及失败状态；确认回调归属、无重复入口、无窄屏溢出。前端类型、lint、测试、构建通过。本地示例验收不触发付费 AI；提交部署另行授权。
