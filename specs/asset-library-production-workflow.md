# Asset Library Production Workflow

## Summary

把项目资产库从“可编辑表单集合”收敛为可靠的项目级角色、场景和道具管理入口。所有可见操作必须有明确结果；生成任务、失败原因和资产版本可刷新恢复；删除、导入和个人空间复用不得破坏已有引用或制造重复数据。

## User Goal

创作者可以在一个明确的项目上下文中维护角色与场景资产，预览真实生成参数，安全生成或替换媒体，并知道资产是否已满足后续短剧生成要求。

## Scope

本次包含：
- 角色参考图、主设定图、主语音和场景/道具资产编辑。
- 主设定图、主语音和资产封面的持久生成状态与错误。
- 图片版本切换、保存到个人空间、引用保护删除。
- 资产确认页的生成前置条件和批量生成过滤。
- 原始素材与 AI 封面的分开展示和替换。

本次不包含：
- 修改冻结的 Go 后端。
- 改造视频生成链路。
- 个人资产库的完整分类和分享系统。

## Workflow

1. 从项目页携带 `project` 参数进入资产库；参数缺失时返回项目页。
2. 编辑资产后先保存，再请求 AI 预览，保证预览和真实生成使用同一份数据库数据。
3. 用户确认后启动生成；状态和错误写入数据库，刷新后仍可见并可重试。
4. 三点菜单提供版本、保存到个人空间和删除等真实动作。
5. 删除前检查镜头和片段引用；有引用时阻止删除并说明原因。
6. 资产确认页只生成满足前置条件的条目；角色缺少参考图时引导回资产库补充。

## Data Shape

- Character:
  - `design_sheet_status`, `design_sheet_error`
  - `voice_reference_status`, `voice_reference_error`
- Asset:
  - `cover_status`, `cover_error`
- AssetRequirement API:
  - `can_generate`, `blocking_reason`

## UI States

- 默认态、加载态、空态和项目参数缺失态。
- 草稿未保存、保存中、保存成功和保存失败。
- 生成中、生成成功、生成失败和重试态。
- 无版本、版本列表、当前版本和切换失败态。
- 被引用无法删除、缺参考图无法生成和不支持自动生成的资产类型。

## API Changes

- 现有角色和资产接口响应增加生成状态与错误字段。
- 现有资产需求响应增加 `can_generate` 与 `blocking_reason`。
- 不新增破坏性 API；版本与保存到个人空间继续使用现有接口。

## Persistence / Async Tasks

- 生成开始前持久化 `generating`，完成后持久化 `succeeded`，异常时持久化 `failed` 和错误文本。
- 图片版本的取消当前版本和插入/切换在事务中完成。
- 保存到个人空间按来源实体更新或插入，不重复创建同一快照。
- 列表 GET 不生成缩略图、不写数据库。

## Failure and Retry

- 失败原因在详情面板和资产需求卡片持续展示，不只使用 Toast。
- 重试使用最新已保存字段重新生成。
- 批量生成跳过缺少角色参考图等不可生成条目，不把产品前置条件记成供应商失败。

## Acceptance Criteria

- 资产库不展示退出登录/账户模块，详情三点菜单无空按钮。
- 角色和资产删除不会使现有片段引用静默失效。
- AI 预览前自动保存当前草稿，刷新页面后仍能看到生成状态和失败原因。
- 原始素材与 AI 封面均可独立查看，资产类型只能选择受支持的标准值。
- 个人空间重复保存不会产生重复记录，重复导入同一需求不会产生孤立实体。
- 资产确认页不会尝试为缺少角色参考图的角色生成主设定图。

## Validation

- Frontend: `cd storyboard-app && npm run build`
- Backend: `cd backend-node && npm run build && npm run test`
- Spec: `npm run check:spec:working`
