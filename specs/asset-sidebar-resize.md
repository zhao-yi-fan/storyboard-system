# 资产侧栏分隔线

默认宽度 384px，范围 320–560px，仅页面会话保留。侧栏左边界显示中性 1px 线，hover/拖动原位变紫；12px 透明命中区居中，不占布局空间，无背景带、发光或双线。

Pointer Events 捕获指针，以起点宽度和位移计算并钳制。关闭、取消、丢失捕获、失焦及进入 <=800px 时停止并恢复原有 body 样式。窄屏隐藏拖动柄，桌面恢复会话宽度。

separator 提供宽度 aria 属性，左键扩大、右键缩小（16px），Home/End 调最小/最大；焦点独立可见。验证类型、lint、测试、构建及 1440/1024/768/390px。业务流程不变，本地修改不发布。
