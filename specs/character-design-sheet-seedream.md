# 角色主设定图改为 Seedream 图生图

## 用户目标

为每个角色生成更稳定、更细节化的主设定图，减少纯文生图导致的人脸、发饰、首饰、服装细节漂移。

## 工作流

1. 在角色资产里上传或填写一张 `角色参考图`。
2. 点击 `生成主设定图`。
3. 后端使用 `Seedream` 图生图：
   - 角色参考图作为人物参考输入。
   - 角色参考图是唯一图片输入。
   - 设定板布局由后端默认 Prompt 描述，不再上传或配置版式参考图；确认前允许编辑最终 Prompt。
4. 生成结果保存到 `design_sheet_url`。

## 数据结构

角色图片字段只保留：

- `avatar_url`
  - 仅用于主设定图生成时的人物参考图
- `design_sheet_url`
  - 角色正式展示图和后续参考图

不再使用：

- `avatar_preview_url`
- `design_sheet_preview_url`

## UI 规则

- 资产库角色详情分成两块：
  - `角色参考图`
  - `角色主设定图`
- `角色参考图` 只说明“用于生成主设定图”，不作为正式展示主图。
- `角色主设定图` 才是角色对外展示结果。
- 没有 `角色参考图` 时，`生成主设定图` 应阻断并提示。

## Prompt 规则

主设定图 prompt 必须明确强调：

- 面部细节
- 发型与发饰
- 耳饰 / 项链 / 腰饰
- 服装结构与花纹
- 面料材质（仅呈现参考图中实际存在的特殊材质）
- 配色方案
- 正面 / 侧面 / 背面三视图
- 左侧头像和配色板；材质、配饰、武器或随身物品细节区仅在参考图中明确存在对应内容时展示
- 右侧人体比例辅助线、身高标尺和缩小全身比例图
- 横向白底专业设定板排版
- 不生成大段文字，避免乱码
- 不得从版式要求引入参考图中不存在的角色特征
- 简单角色或没有明显配饰时省略配饰信息区并重新平衡留白，不得为了填充版面虚构配饰、花纹、武器或道具

版式规则作为后端默认 Prompt 维护。预览接口必须显示默认版式，且参考图输入中只能出现当前角色参考图。预览弹窗允许创作者编辑最终 Prompt；确认生成时前端通过 `prompt_override` 提交，后端校验非空且不超过 10,000 字符后直接用于 Seedream，并将实际 Prompt 写入生成版本。旧客户端未传 `prompt_override` 时继续使用默认模板。

## 失败与重试

- 无 `avatar_url`：直接失败，提示先上传角色参考图。
- Seedream 未配置：直接失败，提示缺少 `SEEDREAM_IMAGE_API_KEY`。
- OSS 下载或保存失败：保留错误信息，不吞掉异常。

## 验收标准

1. 角色无参考图时，无法生成主设定图。
2. 角色有参考图时，主设定图生成固定走 `Seedream` 图生图。
3. 前后端不再依赖任何 `*_preview_url` 角色图片字段。
4. `avatar_url` 不再参与角色正式展示图逻辑。
5. `design_sheet_url` 继续作为角色正式展示图和后续参考图。
6. 生成请求只传入 `avatar_url`，不读取或传入版式参考图。
7. 最终 Prompt 包含固定的横向角色设定板布局和角色一致性约束。
8. 最终 Prompt 可在确认弹窗中编辑，实际生成请求和版本记录使用修改后的文本。
9. 配饰信息区为可选区域，无明确配饰时不会强制生成或虚构内容。
