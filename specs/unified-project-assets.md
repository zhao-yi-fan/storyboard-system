# 统一项目资产工作流

## 用户目标

创作者在同一个项目资产页面按集补齐图片，或维护全部角色、场景、道具；点击资产在同一个右侧详情面板编辑，不离开当前制作上下文。

## 页面与入口

- `/projects/<id>/assets?view=prepare&chapter=<id|all>&kind=<character|scene|prop>` 是准备视图；静态文件继续使用 `/assets/<file>`，两者不重名。
- `view=all` 是全部资产视图；无 view 的旧资产地址默认 all。
- `entity=character:<id>` / `entity=asset:<id>` 打开详情，旧 character 参数兼容。
- 旧 `/asset-confirmation` replace 重定向到准备视图；导入完成默认第一集。
- 旧 `/assets`、`/assets/` 由 Nginx 精确返回 SPA 入口，前端 replace 到新地址；保留 view/chapter/kind/entity/q，旧 character 转换为 entity。无效项目 ID 回项目列表；路径中的项目 ID 是新地址唯一来源。
- 本地旧资产位置读取时归一化为新地址，保持账号/项目隔离；工作台路由此次不迁移。
- 发布验收必须覆盖新旧入口直接打开及刷新、参数保留、JS/CSS 文件正常加载；不把 `/assets/` 前缀整体配置为 SPA。
- 工作台入口统一叫项目资产，并携带当前集。项目列表按账号和项目恢复上次已加载成功的位置；无记录进入工作台。
- 位置只在本浏览器保存，限制为 assets/workspace 的安全参数，不保存草稿、签名 URL；失效集/片段回退有效首项。

## 编辑与状态

- 顶部固定两行：第一行返回工作台和截断项目标题；第二行左侧固定宽度视图页签、右侧独立操作。准备页批量补图入口只在顶部出现，全部资产显示导入/新建。
- 800px 及以下操作区统一独立占一行，两视图保持相同导航高度；切换、数量变化或打开侧栏不移动页签。下方分类、统计、刷新和编辑布局不变。
- 本地布局验收：1440/1024/768/390px 下两视图页签均为 x=16/128、y=69、宽104px；桌面导航高57px、窄屏97px，无页面横向溢出。长标题、侧栏打开、候选数量变化、批量确认及草稿取消/放弃通过；94项前端测试、typecheck、lint、build通过，未触发真实AI生成。

- 两种视图复用资产详情、参数预览、版本、上传、新建及引用保护删除能力。未保存草稿提供保存并继续、放弃、取消；保存失败不离开。
- 版本图片点击只预览；采用版本明确提示项目共享、仅影响后续生成，不替换已有输出。
- 准备页展示有图片、缺图片、生成中及失败计数，不声明制作全部完成。语音独立，不阻塞图片准备；可随时进入工作台。
- 批量补齐范围为选中集（或全部集）的所有分类，确认前显示分类数量和跳过原因。按实体去重，跳过已有图片、缺生成条件及正在生成的对象。
- 有旧图片的再生成失败保留旧媒体，错误持久展示。生成、导入、上传及版本切换后刷新两个视图，不覆盖编辑草稿。
- 生成中可见页每 3 秒对账，后台暂停、恢复立即刷新；轮询错误可重试，不能只展示 Toast。
- 新建项目资产不自动绑定当前集，仍由现有分镜引用与需求同步确定集级需求。

## 接口和数据

- characters/assets 为项目级实体；asset_requirements 为集级引用；asset_versions 保留历史版本，无迁移。
- 需求响应补充 generation_status/generation_error，读取关联实体的图片任务状态，旧 status 保留兼容。
- 生成需求接口增加可选 missing_only 布尔值，新页面传 true；未传保留旧行为。单项重试仍可再生成已有图片。
- 图片生成成功后关联需求状态对账；共享实体批量只调用一次现有生成服务，不新增任务队列。

## 验收

两种视图原地编辑、未保存保护、按集及全部集切换、批量去重及过滤、任务刷新恢复、版本预览不切换、项目/账号隔离的续作位置、旧深链接兼容、OSS 媒体及工作台引用不退化。前后端类型检查、lint、测试，前端构建通过。Go 后端不修改。

## 个人素材交互补充

新增项目快照与替换现有资产图片是不同操作；入口、事务、版本恢复和错误重试约束见 [个人资产新增与选图](personal-asset-image-application.md)。详情选图不覆盖业务身份，也不建立持续同步关系。
